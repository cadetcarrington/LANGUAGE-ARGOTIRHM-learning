## 线形dp

### [数字三角形](898.cpp)

1. 状态表示：

* 集合：所有从起点走到(i, j)的路径
* 属性：集合中所有集合之中的最大值

2. 状态计算：
分类：
    * 来自左上方
    ：```f[i - 1, j - 1] + a[i, j]```
    
    * 来自右下方
    : ```f[i - 1, j] + a[i, j]```

```f[i, j] = max(f[i - 1, j - 1] + a[i, j], f[i - 1, j] + a[i, j])```
### [最长上升子序列](895.cpp)

1. 状态表示：f[i]
    * 集合：所有以第i个数结尾的上升子序列的集合
    * 集合里面长度的最大值

2. 状态计算：
    f[i] = max(f[i], f[j] + 1);
    f[j]是之前的
