## 栈与队列
### 栈
先进后出
```cpp
const int N = 100010;

int stk[N], tt;

//插入
stk[++ tt] = x;

//弹出
tt --;

//判断栈是否为空
if(tt > 0){
    cout << "不空" << endl;
}

//栈顶
stk[tt];
```
### 队列
先进先出
```cpp
//队尾插入元素，队头弹出元素
int q[N], hh, tt = -1;

//插入
q[++ tt] = x;

//弹出  
hh ++;

if(hh <= tt) not empty;

q[hh];//取出队头
```
