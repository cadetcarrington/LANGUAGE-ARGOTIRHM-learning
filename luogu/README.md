# 洛谷刷题

洛谷（luogu.com.cn）刷题代码，文件名即题号，可直接 `g++ 题号.cpp -o 题号` 编译运行。

## 命名规则

- `Pxxxx`：主站题目
- `Bxxxx`：入门题
- `CFxxxx`：Codeforces 题目（洛谷镜像）
- `Txxxxxx`：团队/班级作业题
- 纯数字：组合题号
