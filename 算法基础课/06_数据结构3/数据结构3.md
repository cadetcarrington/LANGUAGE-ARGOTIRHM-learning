### ***字符串哈希***
#### 字符串前缀哈希法

预处理所有前缀的哈希

    eg. str = "ABCDEYSS"

        h[0] = 0, h[1] = "A"(的哈希值), h[2] = "AB" .....
    * 把字符串看成是p进制的数， 字母表示p进制上的数字 -> 把字符串转化成数字
    * mod Q
#### 注意
1. 不能映射成0
2. 哈希数字可能冲突，这里的方法是假设完全不考虑冲突
    
    当p = 131 或者 13331， Q = $2^{64}$;一般不发生冲突

#### 优点
可以利用前缀哈希，计算出任意字串的函数值
$h[R] - h[L] * p ^ {R - L + 1}$

### $vector$ 
**变长数组（倍增思想）**

```cpp
#include <vector>

vector<int> a(10, 3);// 长度为10，每个数的值为3
    //vector<int> a[10];

a.clear() //清空
a.front(), a.back() //第一、最后一个元素
a.push_back(), a.pop_back() //在末位增加、弹出元素
a.begin(), a.end() //第0个和最后一个元素（迭代器）

//支持随机寻址
for (int i = 0; i < a.size(); i ++){
    cout << a[i] << " ";
}cout << endl;

for (vector<int>::iterator i = a.begin(); i != a.end(); i ++){
    cout << * i << endl;
}

for (auto x : a){
    cout << x << " ";
}

//支持比较运算
vector<int> a(4, 3), b(3, 4);
cout << a < b << endl;
```

系统为某一个程序分配空间时，所需的时间与空间大小无关，与申请次数有关
，因此要尽量**减少*****申请空间的次数***
