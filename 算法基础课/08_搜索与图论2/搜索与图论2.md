#### 所有边权都是正数

- 时间复杂度：`O(n^2)`，和边数没有关系

**算法思路**

1. 初始化距离

```cpp
dis[1] = 0, dis[i] = 无穷
```

2. 迭代

```cpp
// S: 当前已经确定最短距离的点
for (i : 0 ~ n)
    t <- 不在 S 中的距离最近的点
    S <- t;
    用 t 更新其他点的距离
    dis[x] > dis[t]
```

#### 存在负权边

**1. Bellman-Ford**

- 时间复杂度：`O(nm)`

- For n次 
for m 次 每一次循环所有边a, b, w(a, b的边，w是权重)

dist[b] <= dist[a] + w; 松弛操作

****若有最短路，图中不能有负权回路****
