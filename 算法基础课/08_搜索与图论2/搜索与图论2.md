## 最短路

> 考察侧重点：**建图**

记号：`n` 为点数，`m` 为边数。

### 单源最短路

#### 所有边权都是正数

**1. 朴素 Dijkstra 算法**

- 时间复杂度：`O(n^2)`，和边数没有关系

**算法思路**

1. 初始化距离

```cpp
dis[1] = 0, dis[i] = 无穷
```

2. 迭代

```cpp
// S: 当前已经确定最短距离的点
for (i : 0 ~ n)
    t <- 不在 S 中的距离最近的点
    S <- t;
    用 t 更新其他点的距离
    dis[x] > dis[t]
```

**2. 堆优化版的 Dijkstra 算法**

- 时间复杂度：`O(m log n)`

#### 存在负权边

**1. Bellman-Ford**

- 时间复杂度：`O(nm)`

**2. SPFA**

- 时间复杂度：一般 `O(m)`，最坏 `O(nm)`

### 多源最短路

**Floyd 算法**

- 时间复杂度：`O(n^3)`
